WHAT WE LEARNED
================================================================================

1. SECTOR-SPECIFIC IS CRITICAL
   - One-size-fits-all approach fails
   - Different sectors have different characteristics
   - Need tailored models for each

2. THRESHOLD OPTIMIZATION IS DANGEROUS
   - Works for good models (Energy, Industrials)
   - Breaks bad models (Tech, Finance, Healthcare raw)
   - Creates sparse signals on weak baselines

3. ENSEMBLE WORKS FOR STABLE, NOT VOLATILE
   - Consensus helps when signals are consistent
   - Overfits when signals are noisy
   - Tech/Finance show ensemble hazard

4. CLASSIFICATION IS SECTOR-SPECIFIC
   - Helps healthcare dramatically (+1.744 gain!)
   - Doesn't help other sectors
   - Direction prediction > return magnitude for healthcare

5. LONGER HOLDING HELPS TREND-FOLLOWING
   - 3 days: good for stable sectors
   - 7 days: critical for healthcare (captures longer trends)
   - Must match sector volatility profile

6. KEEP IT SIMPLE FOR WEAK BASELINES
   - If baseline is already negative, simplify
   - Improvements often hurt more than help
   - Accept lower return if it's stable
