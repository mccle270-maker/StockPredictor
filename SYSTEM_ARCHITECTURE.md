# Stock Predictor System Architecture

## Overview

A comprehensive stock prediction and automated trading system built with Python, featuring machine learning models, technical analysis, options pricing, and paper trading integration.

---

## Core Components

### 1. Prediction Engine (`prediction_model.py`)

**Purpose:** Predicts next-day or multi-day stock returns using ensemble ML models.

**Models Supported:**
- `rf` - Random Forest (default, most stable)
- `xgb` - XGBoost (best Sharpe, tuning-sensitive)
- `gbrt` - Gradient Boosting Regressor
- `linreg` - Linear Regression (baseline)

**Key Functions:**
- `predict_next_for_ticker(ticker, period, model_type, horizon)` - Main prediction entry point
- `predict_long_horizon_for_ticker(ticker, period)` - 30-day analog/regime prediction
- `build_features_and_target(ticker, period, horizon)` - Feature engineering pipeline
- `walk_forward_backtest()` - Proper date-based backtesting
- `train_model()` - Model training with 80/20 split

**Feature Categories (100+ features):**

| Category | Features | Description |
|----------|----------|-------------|
| **Price/Returns** | `ret_1d`, `ret_5d`, `ret_20d`, `cumret_5d` | Historical returns |
| **Volatility** | `vol_10d`, `vol_20d`, `vol_60d`, `atr_14` | Rolling volatility measures |
| **Technical** | `rsi14`, `macd`, `macdsignal`, `mfi14`, `adx_14` | TA-Lib indicators |
| **Trend** | `sma_20`, `sma_50`, `ema_12`, `ema_26` | Moving averages |
| **Volume** | `vol_ma20_ratio`, `obv`, `vwap` | Volume analysis |
| **GBM** | `gbm_prob_up_1d`, `gbm_exp_ret_1d` | Geometric Brownian Motion probabilities |
| **Macro** | `vix`, `t10y`, `term_spread`, `fed_funds` | FRED economic data |
| **Fundamentals** | `fund_pe_trailing`, `fund_pb`, `fund_marketcap` | FMP company data |
| **Sentiment** | `news_sentiment`, `news_count` | Marketaux news scores |
| **Regime** | `regime_bull`, `regime_bear`, `vix_regime` | Market regime detection |

**Output Format:**
```json
{
  "ticker": "AAPL",
  "pred_next_ret": 0.0123,
  "pred_next_price": 195.50,
  "prob_up": 0.65,
  "prob_down": 0.35,
  "confidence_score": 0.0123,
  "vol_20d": 0.18,
  "last_close": 193.12,
  "model_type": "rf",
  "horizon": 1
}
```

### 2. Long-Horizon Prediction (`long_horizon.py`)

**Purpose:** 20-30 day outlook using historical analog matching and regime detection.

**Method:**
1. Build slow/structural features (50-day slope, volatility percentile, momentum)
2. Tag current market regime (up/down trend × low/med/high volatility)
3. Find similar historical periods using cosine similarity
4. Weight by recency (exponential decay) and similarity
5. Return probability distribution of forward returns

**Output:**
```json
{
  "p_up_30d": 0.62,
  "ret_p10_30d": -0.05,
  "ret_p50_30d": 0.02,
  "ret_p90_30d": 0.08,
  "vol_expansion_prob": 0.35,
  "flags": {"low_confidence": false, "regime_shift_risk": false},
  "effective_sample_size": 45
}
```

### 4. Options Pricing (`option_pricing.py`, `monte_carlo_pricer.py`)

**Pricing Models:**

**Features:**

### 5. Automated Trading (`auto_paper_trade.py`)

**Broker:** Alpaca (paper trading)

**Trade Flow:**
1. Read `signals.json` generated by prediction model
2. Filter for US-tradeable symbols only
3. Execute market/limit orders for stocks
4. Execute option orders (with DTE/strike/premium filters)

**Order Types:**
- Market orders (default for stocks)
- Limit orders (for options)
- Spread orders (bull call, bear put, iron condor)

**Risk Controls:**
- Max contracts per trade
- Premium caps
- DTE min/max filters
- Position sizing by confidence

## API Endpoints (for Mobile App Integration)

To expose this as an API for a mobile app, you would need to wrap the core functions:

### Prediction Endpoint
```python
# GET /predict/{ticker}
from prediction_model import predict_next_for_ticker, predict_long_horizon_for_ticker

def get_prediction(ticker: str, horizon: int = 1, model: str = "rf"):
    short_term = predict_next_for_ticker(ticker, period="5y", model_type=model, horizon=horizon)
    long_term = predict_long_horizon_for_ticker(ticker, period="5y")
    return {
        "short_term": short_term,
        "long_term": long_term
    }
```

### Watchlist Endpoint
```python
# POST /watchlist/analyze
def analyze_watchlist(tickers: list[str], horizon: int = 1):
    results = []
    for ticker in tickers:
        pred = predict_next_for_ticker(ticker, horizon=horizon)
        results.append(pred)
    return sorted(results, key=lambda x: abs(x["pred_next_ret"]), reverse=True)
```

### Signals Endpoint
```python
# GET /signals
def get_trading_signals():
    import json
    with open("signals.json") as f:
        return json.load(f)
```

## Key Algorithms

### Feature Engineering
- All features lagged by 1 day (`.shift(1)`) to prevent look-ahead bias
- NaN handling: `.ffill().bfill().fillna(0)`
- Target: forward return shifted by horizon days

### Model Training
- 80/20 chronological train/test split
- Optional Elastic Net feature selection
- Walk-forward validation for proper backtesting

### Regime Detection
- Trend: 50-day slope (up/down)
- Volatility: 20-day HV percentile (low/med/high)
- Combined regime tag for analog matching

### Signal Generation
- Threshold-based (return > 0.25% → trade)
- Confidence-weighted position sizing
- Strategy mapping (bullish → calls, bearish → puts)

## Performance Metrics

- **Sharpe Ratio**: Risk-adjusted returns
- **Direction Accuracy**: % of correct up/down predictions
- **Max Drawdown**: Largest peak-to-trough decline
- **Deflated Sharpe**: Multiple-testing adjusted Sharpe
